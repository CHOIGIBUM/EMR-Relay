EMS Relay MVP 실행 및 시연 안내

1. 압축을 원하는 폴더에 풉니다.
2. Node.js 22 이상이 설치되어 있는지 확인합니다.
3. RUN_LOCAL_MVP.bat을 더블클릭합니다.
4. 처음 실행할 때는 필요한 구성요소를 설치하므로 인터넷 연결이 필요합니다.
5. 창에 표시되는 http://localhost:3000 주소를 브라우저에서 엽니다.

역할별 화면을 동시에 확인하려면 같은 브라우저에서 아래 주소를 새 탭으로 엽니다.
- 구급대원: http://localhost:3000/?view=mobile
- 이송조정 상황실: http://localhost:3000/?view=control
- 병원: http://localhost:3000/?view=hospital
- 전체 기록: http://localhost:3000/?view=workflow

한 탭의 버튼 조작은 다른 탭에 자동 반영되고, 새로고침 후에도 현재 상태가 복원됩니다.

권장 시연 순서

1. 구급대: EMS-GW-001 선택 → 출동 시작 → 현장 도착 → 환자 접촉
2. 구급대: 활력징후 입력 → AVPU·CPSS 확인 → 누르고 말하기 → 확인본 생성
3. 구급대: 상황실에 병원 조정 요청
4. 상황실: 병원 후보 확인 → 선택 병원에 수용 확인 요청
5. 병원: 항응고제 복용 여부 추가정보 요청
6. 구급대: 확인 결과를 미상으로 회신
7. 병원: 수용 가능 회신
8. 구급대: 이송지 확인 → 이송 시작 → 재평가 → 병원 도착 → 인계
9. 병원: 인수 담당자 입력 → 환자 인수 확인
10. 전체 흐름: 세 사용자 기록과 자동 타임라인 확인

시연을 처음부터 다시 시작하려면 화면 오른쪽 위의 초기화를 누릅니다.
종료하려면 실행 창에서 Ctrl+C를 누릅니다.

참고: AWS와 외부 Agent API는 필요하지 않습니다. 음성 정리와 병원정보 조회는 로컬 모의 API가 대신합니다. 실제 119 지령시스템, 의료기관 EMR 또는 실시간 수용정보와 연결되어 있지 않습니다.
