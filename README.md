# EMS Relay MVP

급성 뇌졸중 의심 환자 한 명의 신고·현장평가·병원 조정·이송·인계 과정을 구급대원 모바일, 이송조정 상황실 웹, 병원 웹에서 이어서 시연하는 React 프론트엔드입니다.

## 실행 방법

Windows에서 압축을 푼 뒤 `RUN_LOCAL_MVP.bat`을 더블클릭합니다.

1. 첫 실행에서는 필요한 패키지가 자동으로 설치됩니다.
2. 터미널에 표시되는 `http://localhost:3000` 주소를 브라우저에서 엽니다.
3. 상단의 `구급대`, `상황실`, `병원`, `전체 흐름`을 눌러 같은 사건의 사용자 화면을 전환합니다.
4. 종료할 때는 터미널에서 `Ctrl+C`를 누릅니다.

Node.js 22 이상과 최초 설치를 위한 인터넷 연결이 필요합니다.

AWS 계정과 외부 Agent API는 필요하지 않습니다. 로컬 모의 API가 음성 정리와 병원정보 조회를 대신하며, 역할별 화면을 여러 탭으로 열면 같은 사건 상태가 서로 갱신됩니다. 자세한 내용은 `LOCAL_MVP.md`를 확인하세요.

## 시연 사건

- 사건번호: `EMS-GW-001`
- 강원 군 지역에 거주하는 78세 독거 여성
- 이웃이 말 어눌함과 우측 얼굴·팔 위약을 발견해 신고
- LNT 13:40, FAT 14:15
- AVPU A, CPSS 양성
- BP 178/96 mmHg, PR 92회/분, RR 18회/분, SpO₂ 97%, BST 118 mg/dL
- 고혈압·당뇨, 항응고제 복용 여부 미상

## 권장 시연 순서

1. 구급대: 사건 선택 → 출동 시작 → 현장 도착 → 환자 접촉
2. 구급대: 측정값 입력 → `누르고 말하기` → 내용 확인 → 환자 확인본 생성
3. 구급대: 상황실에 병원 조정 요청
4. 상황실: 병원 후보 한 곳 선택 → 수용 확인 요청
5. 병원: 추가정보 요청에서 `항응고제 복용 여부` 선택
6. 구급대: 요청 항목을 `미상`으로 회신
7. 병원: 수용 가능 회신
8. 구급대: 이송지 확인 → 이송 시작 → 재평가 → 병원 도착
9. 구급대: 구두·전자 인계 완료
10. 병원: 인수자 입력 → 환자 인수 확인
11. 전체 흐름: 세 사용자 기록과 자동 타임라인 확인

## 구현된 기능

- 세 사용자 화면이 하나의 공통 사건 상태와 기록을 공유
- 출동 시작·현장 도착·환자 접촉·이송 시작·병원 도착·인계·인수의 단계별 확인
- 버튼을 누른 사건 시각, 행위자와 역할을 공통 타임라인에 저장
- 활력징후·AVPU·CPSS의 실제 선택·입력
- 중앙 PTT 오버레이, 실시간 발화 예시와 구조화 후보 확인
- 상황실의 단일 활성 병원 요청과 수용 곤란 시 다음 병원 선택
- 병원의 추가정보 요청·수용 가능·수용 곤란 회신
- 이송 ETA, 재평가, 최종 인계 카드와 양측 인수 확인
- 모바일 스크롤, 고정 작업 버튼·하단 메뉴, 데스크톱 3열 업무 화면
- 반응형 레이아웃과 키보드 포커스

현재 데이터는 브라우저 메모리에 유지되며 새로고침하거나 `시연 초기화`를 누르면 처음 상태로 돌아갑니다. 실제 119 지령시스템·병원 EMR·실시간 수용정보와 연결하지 않은 프론트엔드 MVP입니다.
