# EMS Relay 수동 시연 순서와 음성 대본

## 1. 준비

- 서비스: https://main.d1b1dqlcfz85e3.amplifyapp.com
- 구급대원 계정: `paramedic.demo@emsrelay.kr`
- 통합 병원 계정: `hospital.network@emsrelay.kr`
- 비밀번호 확인 위치: AWS Secrets Manager `ems-relay/demo-users`
- 구급대원 화면과 병원 화면은 서로 다른 브라우저 또는 일반 창/시크릿 창으로 연다.
- 구급대원 화면 우측 상단의 **초기화**를 한 번 누르고 `EMS Relay-001`을 선택한다.

## 2. 출동과 현장 도착

1. **출동 시작**을 누른다.
2. 지도에서 출발지 `영랑119안전센터`, 목적지 `강원특별자치도 속초시 중앙로147번길 16`, 두 지점의 표식과 연결 경로를 확인한다.
3. **카카오맵 길찾기**를 누른다.
4. 현재 GPS가 아니라 위 출발지와 목적지가 고정된 자동차 길찾기로 열리는지 확인한다.
5. 원래 화면으로 돌아와 **현장 도착**, 이어서 **환자 접촉**을 누른다.
6. 별도 중간 안내 화면 없이 바로 3단계 환자 상태 입력 화면으로 넘어가는지 확인한다.

## 3. 환자 상태 입력

각 단계에서 **음성 입력을 누른 채 말하고 손을 뗀다.** 실시간 인식 문장을 확인한 뒤 AI 정리 초안에서 맞는 항목만 선택하고 **선택값 적용**을 누른다. 빠진 항목은 수동 선택·휠 입력으로 보완한다.

### 1단계 — 기본 확인

> 환자는 74세 여성입니다. 기도는 개방되어 있고 자발호흡합니다. 맥박은 촉지됩니다. 의식은 V로, 부르면 반응합니다. 갑자기 말이 어눌해지고 오른팔에 힘이 빠졌습니다.

확인값:

- 나이: 74세
- 성별: 여성
- 기도: 개방
- 호흡: 자발호흡
- 순환: 맥박 촉지
- AVPU: V
- 주호소: 갑작스러운 구음장애와 오른팔 위약

### 2단계 — CPSS

> 안면 마비는 오른쪽이고, 팔 떨어짐도 오른쪽입니다. 언어는 구음장애입니다.

확인값:

- 안면 마비: 우측
- 팔 떨어짐: 우측
- 언어 이상: 구음장애

### 3단계 — 활력징후와 시간

> 혈압은 178에 96, 맥박은 분당 92회, 호흡수는 분당 18회, 산소포화도는 97퍼센트, 혈당은 118입니다. 마지막 정상 확인은 8시 30분이고 보호자가 목격했습니다. 최초 이상 발견은 8시 45분, 활력 측정 시각은 8시 54분입니다.

확인값:

- BP: 178/96 mmHg
- PR: 92회/분
- RR: 18회/분
- SpO₂: 97%
- 혈당: 118 mg/dL
- 마지막 정상 확인: 08:30 / 보호자 목격
- 최초 이상 발견: 08:45
- 활력 측정 시각: 08:54

마지막으로 **환자 카드 확정**을 누르고 카드가 열리는지 확인한다.

## 4. 근거리 병원 동시 요청

1. **근거리 병원 동시 요청**을 누른다.
2. 브라우저가 알림 권한을 물으면 허용한다. 화면 알림은 항상 표시되며, 브라우저 알림은 기기 지원과 권한에 따라 함께 표시된다.
3. 지도에서 현장, 요청 반경, 병원 상태 표식, 레이더형 확장 효과를 확인한다.
4. 초기 범위는 15km이며 속초의료원과 온재병원 요청이 표시되는지 확인한다.
5. 하단 왼쪽에 **요청 범위 확대**, 오른쪽에 **병원 요청 갱신**이 있는지 확인한다.

### 자동 확대를 확인하는 방법 — 하나만 선택

#### A. 전부 수용 곤란

1. 병원 화면 상단에서 `강원특별자치도속초의료원`을 선택한다.
2. 좌측 요청을 열어 **NO · 수용 곤란**으로 회신한다.
3. 상단 병원 선택기를 `의료법인온세움의료재단온재병원`으로 바꾼다.
4. 같은 사건을 열어 **NO · 수용 곤란**으로 회신한다.
5. 모든 현재 요청이 거절되면 `15→30→60→120km`가 즉시 진행되고, 후보가 없는 중간 반경은 자동으로 건너뛴 뒤 강릉권 병원 요청이 추가되는지 확인한다.

#### B. 미회신 시간 만료

1. 초기 요청 중 한 곳 이상을 `요청 중` 또는 `열람` 상태로 그대로 둔다.
2. 지도 안내에 표시된 자동 확대 시각까지 약 30초 기다린다.
3. 자동으로 다음 반경이 진행되고 강릉권 후보가 추가되는지 확인한다.

#### C. 구급대원 수동 확대

1. 구급대원 화면의 **요청 범위 확대**를 누른다.
2. 자동 대기 시간을 기다리지 않고 다음 반경 탐색이 시작되는지 확인한다.

같은 사건에서 A·B·C를 섞으면 예약된 자동 확대와 수동 확대 시점이 겹칠 수 있으므로, 한 방법만 확인한 뒤 다른 방법은 **초기화** 후 다시 시연한다.

## 5. 병원 수용과 알림

1. 병원 화면 우측 상단 선택기에서 현재 요청이 도착한 병원을 선택한다.
2. 요청을 열어 환자 카드, ETA, 도로 거리를 확인한다.
3. **YES · 수용 가능**으로 회신한다.
4. 구급대원 화면 상단에 병원명과 함께 **수용 가능 회신** 알림이 즉시 나타나는지 확인한다.
5. 권한을 허용한 지원 브라우저에서는 시스템 알림·진동도 확인한다.
6. 구급대원이 수용 가능 병원 목록에서 **이 병원 선택**을 누른다.

## 6. 병원 이동과 종료

1. 선택 병원의 이름, ETA, 거리, 주소가 표시되는지 확인한다.
2. **카카오맵 길찾기**를 눌러 출발지가 환자 현장, 목적지가 선택 병원으로 고정되는지 확인한다.
3. **병원으로 출발**을 누른다.
4. 병원 화면에서 해당 요청이 `이송 병원으로 선택됨`으로 바뀌는지 확인한다.
5. 구급대원 화면에서 **병원 도착**을 눌러 이송 완료 화면까지 진행한다.

## 7. 판정 기준

- 자동 확대: 모두 거절 시 즉시, 미회신 시 30초 후
- 반경: 15km → 30km → 60km → 120km
- 병원 결정: 시스템이 자동 선택하지 않고, YES 회신 병원 중 구급대원이 최종 선택
- 지도: 내 현재 위치가 아니라 사건에 설정된 출발지·현장·병원 좌표 사용
- 병원 계정: 하나의 통합 계정에서 허용된 시연 병원을 전환
- 수용 알림: 화면 알림은 필수, 시스템 알림·진동은 브라우저 지원 시 보조 제공
